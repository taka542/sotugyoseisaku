■サービス概要
日替わりで１日１個の英単語とその英単語を使った例文を１文だけ表示する。
背景には面白い画像を背景にして視覚的にも楽しめる。数秒ごとに画像が変わる。
英語を勉強する習慣が全く無い人や英語の勉強が続かない人の英語の勉強のきっかけにしたいサービス。

■ このサービスへの思い・作りたい理由
自分自身英語の勉強が続かないので英語の勉強をするきっかけになるアプリを作れないかと思った。
面白い背景画像を設置することで画像を楽しみながらこのアプリで英語の勉強をできる。
私は画像生成AIで作った画像を見る時間が長いので背景画像に画像生成AIで作った画像を設置したいと思った。

■ ユーザー層について
英語の勉強が続かないユーザー層

■サービスの利用イメージ
１日１単語と少なくすることで勉強のハードルを下げたことにより英語の勉強に取っかかりやすくなった、
英語の勉強しながらも面白い背景画像でさらに視覚的にも楽しみながらアプリを利用できる。


■ ユーザーの獲得について
ランテックのプロフィールのアプリ欄で公開する。

■ サービスの差別化ポイント・推しポイント
背景の面白い画像が数秒ごとに切り替わることで英語だけでなく画像も楽しめる。
